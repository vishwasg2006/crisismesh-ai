# CrisisMesh AI – Frontend

An offline-first emergency response coordination
platform built using HTML, CSS and Vanilla JavaScript.

## Technologies

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- Node.js REST APIs

## Setup

1. Open the frontend folder in VS Code.
2. Start the backend server.
3. Configure the backend URL in js/api.js.
4. Open index.html using Live Server.

## Pages

- index.html – Landing page
- coordinator.html – Coordinator dashboard
- responder.html – Field responder dashboard

## Features

- Emergency incident monitoring
- Resource allocation
- Field responder management
- Interactive emergency map
- Offline report storage
- Reconnection and synchronization
- Conflict notifications

## Project Mode

Simulation / Prototype

This application does not contact real emergency
services or transmit real distress signals.
